# 验证样例：TASK-TAG-FILTER 任务列表接口支持按标签过滤

## 1. 任务描述

业务工程：`sample_app/`（任务看板 `taskboard`，Python 标准库 WSGI 服务 + pytest）。任务定义：`sample_task/task.toml`。

**要改什么**：为 `GET /tasks` 增加查询参数 `tag`（规格条目 TAG-001～TAG-004）

- 只返回 `tags` 中包含该标签的任务，没有匹配时返回空列表；
- 匹配忽略大小写和首尾空白；
- 与 `status` 过滤取交集，排序、`limit`、`total` 规则不变；
- `tag` 为空或全是空白时视为非法输入：`search_tasks` 抛出 `QueryError`，接口返回 400。

**哪些原有行为必须保持**（规格条目 LIST-001～LIST-005）：默认按优先级再按 id 排序；`status` 过滤与非法值返回 400；
`limit` 取值 1–100 且 `total` 不受其影响；响应结构 `{"items": [...], "total": n}`；**未知查询参数被忽略**。
此外创建任务（CRT-*）与 CSV 导出（EXP-*）的测试作为全量回归一并运行。

修改范围：只允许修改代码文件，测试与规格不得改动；模块会拒绝 MiniMax 对 `tests/`、`specs/` 的任何修改。

## 6. 重置方法

```bash
bash scripts/reset.sh             # 停止 PowerContext Server，删除 .runtime（seekdb 数据、PowerContext 数据、工作副本）
bash scripts/reset.sh --evidence  # 同时把 evidence/、snapshots/ 恢复为仓库提交的版本
./sdd spec-update --restore       # 只把工作副本的规格恢复为 v1（之后重新 ./sdd ingest）
```

`sample_app/` 本身从不被修改，重置后重新运行 `bash scripts/demo_accept.sh` 即可从空状态复现。
