# 任务列表按标签过滤（GET /tasks?tag=）

- 组件: GET /tasks
- 版本: v2
- 状态: 生效

为任务列表接口增加按标签过滤的能力。v2 在 v1 基础上支持在一次请求中指定多个标签，并限制标签数量。

## TAG-001 按标签过滤任务（支持多个标签）
- 类型: 变更
- 关键词: tag, 标签, 过滤, 查询参数, 多个标签, filter

`GET /tasks` 的查询参数 `tag` 可以重复出现（例如 `?tag=backend&tag=bug`），此时只返回同时包含全部指定标签的任务；只出现一次时与 v1 相同，只返回 `tags` 中包含该标签的任务。没有任务匹配时返回 `{"items": [], "total": 0}`。

## TAG-002 标签匹配规则
- 类型: 变更
- 关键词: tag, 标签, 大小写, 空白, 匹配

`tag` 参数值先去除首尾空白，再与任务标签进行不区分大小写的比较。例如 `?tag=%20Backend%20` 与标签 `backend` 匹配。

## TAG-003 与现有过滤、排序和分页组合
- 类型: 变更
- 关键词: tag, status, limit, total, 组合, 排序

`tag` 与 `status` 同时提供时取交集。排序规则（LIST-001）与 `limit` 规则（LIST-003）不变；`total` 是应用全部过滤条件之后、`limit` 截断之前的数量。

## TAG-004 空标签参数
- 类型: 变更
- 关键词: tag, 空值, 空白, 边界输入, 400

`tag` 参数存在但为空字符串或只包含空白时视为非法查询：`search_tasks` 抛出 `QueryError`，接口返回 HTTP 400，错误信息包含 `tag`。

## TAG-005 标签数量上限
- 类型: 变更
- 关键词: tag, 标签, 数量上限, 边界输入, 400

同一请求中 `tag` 最多出现 5 次；超过时视为非法查询，接口返回 HTTP 400，错误信息包含 `tag`。
