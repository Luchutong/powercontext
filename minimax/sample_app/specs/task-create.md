# 创建任务接口（POST /tasks）

- 组件: POST /tasks
- 版本: v1
- 状态: 生效

## CRT-001 标题校验
- 类型: 保持
- 关键词: title, 标题, 校验, 422

标题必填；去除首尾空白后长度必须在 1–80 之间，否则返回 HTTP 422，错误信息包含 `title`。

## CRT-002 默认值
- 类型: 保持
- 关键词: 默认值, id, status, priority

新任务的 `id` 为当前最大 `id` 加 1，状态固定为 `open`；未提供 `priority` 时取 `medium`。

## CRT-003 标签规范化
- 类型: 保持
- 关键词: tags, 标签, 小写, 去重, 存储

创建任务时，标签去除首尾空白并转为小写，丢弃空值并去重（保留首次出现的顺序）后再存储。
