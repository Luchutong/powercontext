📥 一键导入

指定一个文件夹，自动读取 Markdown / TXT / PDF，切成适合检索的片段；也可以在网页里直接上传。

🧠 混合检索

关键词精确命中 + 语义相近召回，两路结果融合排序，换个说法也能找到。

🏷️ 按类别筛选

子文件夹自动成为类别（科研 / 工作 / 行政 / 学习），一键缩小范围。

📍 定位到段落

结果直接给出文件名和第几段，并高亮关键词，不用再打开整份文件。

原理：seekdb 混合检索

一个嵌入式数据库同时完成全文索引、向量索引和融合排序

你的资料Markdown / TXT / PDF
按段落切片，约 400 字一段
→
全文索引IK 中文分词
"发票""财务" 精确命中
向量索引bge-small-zh 语义向量
"什么时候交" ≈ "25 日前提交"
→
RRF 融合排序两路排名合并
返回最相关的片段与出处

核心代码（zhiku/store.py）

res = self.col.hybrid_search(
    query={"where_document": {"$contains": keyword_query(q)}, "n_results": k * 3},  # 全文
    knn={"query_texts": [q], "n_results": k * 3},                                  # 向量
    rank={"rrf": {}},                                                               # 融合
    n_results=k,
    include=["documents", "metadatas"],
)

快速开始

需要 Python 3.11+，Linux 或 macOS

git clone -b 2026-competition-ecosystem https://github.com/Luchutong/powercontext.git
cd powercontext/qoder
pip install -r requirements.txt

# 导入示例资料（首次会下载约 95MB 的中文向量模型）
python -m zhiku ingest ./sample_docs

# 运行验证样例，生成 seekdb 检索记录 docs/verify-log.md
python -m zhiku verify

# 打开网页界面：http://127.0.0.1:8000
python -m zhiku serve --docs ./sample_docs

想用自己的资料，把 ./sample_docs 换成你的文件夹即可，子文件夹名会成为类别。
