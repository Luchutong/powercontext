# 论文笔记：检索增强生成（RAG）中的混合检索

> 示例资料，内容为个人学习笔记。

## 为什么要混合检索
纯向量检索擅长语义相近的召回，但对专有名词、型号、编号、人名这类精确词很不敏感，经常把"语义差不多但关键词不对"的段落排到前面。
关键词（全文）检索正好相反：精确词命中率高，但换个说法就搜不到。

混合检索把两路结果合并，兼顾"说法不同也能找到"和"关键词必须对上"。

## 常见融合方法
- RRF（Reciprocal Rank Fusion）：只看每路结果的排名，score = Σ 1/(k + rank)，不需要对两路分数做归一化，简单稳健。
- 加权分数融合：需要把向量距离和 BM25 分数归一化到同一尺度，调参成本较高。

## 切片（chunk）经验
- 中文资料每段 300~500 字效果较好；太短丢上下文，太长稀释相关性。
- 相邻切片保留少量重叠，避免关键句被切断。

## 中文分词
全文检索对中文必须做分词，常用 IK 分词器，否则"消融实验"和"消融分析"无法部分匹配。
